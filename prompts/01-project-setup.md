# 01 – Project Setup

## Prompt

```
Set up the project structure for my university assignment in this folder:
1. Create folders: prompts/, src/, assets/screenshots/, docs/
   (add an empty .gitkeep file in each so Git keeps them).
2. Create prompts/01-project-setup.md and save this exact prompt in it,
   with a short note on what you did.
3. Update README.md with a short intro: course "AI Agents & Vibe Coding",
   University of Haifa, Exercise 1, team: Raneem Daher & Raghad Rabah
   status: project setup. Add an empty "Progress Log" section at the end.

Before pushing:
- Show me a summary of the changes and wait for my approval.
- Write a commit message with a short title, plus 2-3 lines explaining
  what changed, why, and whether it is a critical change or a minor one.
- Add a line to the "Progress Log" section in README.md with the date
  and what was done in this step.
After I approve, commit and push to GitHub.
```

## Note on what was done

- Created the folders `prompts/`, `src/`, `assets/screenshots/` and `docs/`, each with an empty `.gitkeep` so Git tracks them.
- Saved this prompt in `prompts/01-project-setup.md`.
- Rewrote `README.md` with a short project intro (course, university, exercise, team, status) and added a "Progress Log" section with the first entry for this step.
